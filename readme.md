# Карта книжных путешествий

Open-source веб-сайт с интерактивными картами литературных путешествий. Пользователь выбирает книгу, видит маршрут героев на карте, кликает по точкам маршрута и читает краткое описание места, главы, эпизода и редакторскую заметку.

В проекте есть собственный маршрут **Жюль Верн — «Вокруг света за 80 дней»** и каталог маршрутов из открытого проекта Read the Places.

## Что уже есть

- главная страница с заголовком, описанием и выбором книги;
- интерактивная карта на Leaflet и OpenStreetMap;
- линия маршрута и кликабельные точки;
- карточка выбранного места;
- таймлайн маршрута с перемещением карты к точке;
- JSON-данные маршрута в `data/books/around-the-world-in-80-days.json`;
- 427 импортированных книг и 2 280 точек из Read the Places;
- TypeScript-типы для будущих книг и маршрутов;
- детский режим: 5 маршрутов, задания, штампы и обозначение «правда / выдумка».

## Детский режим

Переключатель «Атлас книг / Детям» на главной странице. В детском режиме:

- **подборка из 5 книг** с возрастом и временем прохождения;
- **штампы** за каждую точку маршрута — хранятся в `localStorage`, без регистрации и без отправки данных на сервер;
- **задания** с тремя вариантами ответа на каждой точке;
- **«правда / выдумка»** — цвет маркера зависит от поля `certainty`: зелёный — точное место, оранжевый — примерное, фиолетовый — вымышленное. Легенда под картой;
- **расстояние** от предыдущей точки и сравнение с понятным масштабом («как от Москвы до Петербурга»);
- **транспорт**: между точками едет поезд, плывёт пароход, скачет лошадь или идёт пешеход — в зависимости от поля `transport` у точки. Там, где транспорт не указан, движется нейтральная пульсирующая точка;
- **кнопка «В путь»**: маршрут проигрывается целиком, от точки к точке;
- **мобильная раскладка**: карта, лента точек и карточка друг под другом.

Данные детского режима лежат отдельно от общего атласа — в `data/kids/collection.json`. Английские тексты Read the Places не переписываются: для каждой книги задаётся свой русский текст, который накладывается поверх исходных данных (`lib/kids.ts`). Для собственных маршрутов в том же файле можно указать полный массив `route` (так сделан «Дети капитана Гранта»).

Чтобы добавить книгу в детскую подборку:

1. Добавьте объект в `data/kids/collection.json` с полями `id`, `title`, `author`, `emoji`, `ageFrom`, `ageTo`, `minutes`, `tagline`, `description` и `points`;
2. В `points` для каждой точки маршрута укажите `order` и, при необходимости, `displayName`, `country`, `summary`, `note`, `certainty` и `quest`;
3. Если книга уже есть в каталоге Read the Places, маршрут загрузится по `id` через `/api/books/[id]`. Если маршрут свой — добавьте массив `route` прямо в объект.

Поле `transport` у точки описывает, **как герои добрались до этого места**. Поддерживаются значения `plane`, `train`, `steamship`, `ship`, `boat`, `ferry`, `car`, `bus`, `bicycle`, `horse`, `camel`, `elephant`, `carriage`, `walk`, `dogsled` (см. `lib/transport.ts`). Если поле не задано, между точками движется нейтральный маркер.

## Как запустить локально

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Как добавить новую книгу

1. Создайте новый JSON-файл в `data/books/`, например `treasure-island.json`.
2. Заполните данные в формате `BookRoute`: название, автора, описание и массив `route`.
3. Добавьте импорт нового файла в `app/page.tsx`.
4. Добавьте книгу в массив `books`.

Минимальный формат точки маршрута:

```json
{
  "order": 1,
  "place": "London",
  "displayName": "Лондон",
  "country": "Великобритания",
  "lat": 51.5072,
  "lng": -0.1276,
  "chapter": 1,
  "certainty": "exact",
  "transport": "start",
  "summary": "Краткое описание эпизода.",
  "quote": "",
  "note": "Заметка редактора."
}
```

Поле `certainty` поддерживает значения:

- `exact` — точное место;
- `approximate` — примерное место;
- `fictional` — вымышленное место.

## Импорт Read the Places

Исходный репозиторий клонируется в `readtheplaces-source/` и не попадает в Git. Чтобы обновить каталог:

```bash
npm run import:readtheplaces
```

Данные `books/*/book.json` и `books/*/waypoints.json` проекта Read the Places распространяются по лицензии CC BY-SA 4.0. В интерфейсе сохраняются название источника и ссылка на лицензию. Тексты произведений не импортируются.
