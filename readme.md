## mapbook

**mapbook** — это простой сайт с картами книжных путешествий.

Идея проекта: показать, что книга — это не просто текст, а настоящее приключение.
Читатель выбирает книгу, открывает карту и проходит маршрут вместе с героями.

Проект сначала делается как семейный сайт для девочки 13 лет, чтобы мягко заинтересовать её чтением через карты, выбор, путешествия и игровые элементы.

---

## Что умеет сайт

В первой версии сайт должен уметь:

* показывать список книг;
* открывать выбранную книгу;
* показывать маршрут героев на карте;
* показывать точки маршрута;
* открывать карточку каждой точки;
* отмечать точки как пройденные;
* сохранять прогресс в браузере;
* давать возможность писать личные заметки к точкам маршрута.

---

## Главная идея

Пользователь не «проходит тест» и не «сдаёт чтение».

Он путешествует по книге.

Лучше писать:

> Когда узнаешь, куда герой отправился дальше, открой новую точку маршрута.

Не писать:

> Ты должна прочитать следующую главу.

---

## Для кого проект

Сначала проект делается для подростка 13 лет.

Поэтому сайт должен быть:

* простым;
* тёплым;
* не похожим на школьный дневник;
* без оценок;
* без давления;
* с ощущением личного приключения.

Пользователь должен чувствовать себя не учеником, а исследователем, редактором и путешественником.

## Первая книга для разработки

Начать лучше с книги **«Остров сокровищ»**.

Почему:

* понятный приключенческий сюжет;
* есть карта;
* есть море;
* есть пираты;
* есть тайна;
* маршрут можно сделать коротким и наглядным.

Пример точек:

1. Трактир «Адмирал Бенбоу»
2. Бристоль
3. Корабль «Испаньола»
4. Остров сокровищ
5. Форт
6. Место клада

## Технологии

Первая версия должна быть максимально простой.

Использовать:

* HTML;
* CSS;
* JavaScript;
* Leaflet для карты;
* данные в файле `data.js`;
* `localStorage` для сохранения прогресса и заметок.

Не использовать в первой версии:

* backend;
* базу данных;
* регистрацию;
* авторизацию;
* сложную админку;
* фреймворки;
* сборщики;
* серверную часть.

Сайт должен запускаться просто: открыть файл `index.html` в браузере.

mapbook/

### Назначение файлов

`index.html`
Основная страница сайта.

`style.css`
Оформление сайта.

`script.js`

Описание проекта.

## Как запустить

1. Скачать проект.
2. Открыть папку `mapbook`.
3. Открыть файл `index.html` в браузере.

Для первой версии этого достаточно.

## Основной экран

На главной странице должно быть:

```text
Привет, путешественница!
Выбери книгу — и отправляйся по следам героев.
```

Ниже — карточки книг.

Пример карточки:

```text
Остров сокровищ
Пираты, карта, тайна старого капитана и опасный остров.
```

## Как работает маршрут

Когда пользователь выбирает книгу:

1. На карте появляются точки маршрута.
2. Появляется список точек.
3. При клике на точку открывается карточка.
4. В карточке есть описание события.
5. Есть вопрос для размышления.
6. Есть поле для личной заметки.
7. Есть кнопка «Отметить как пройдено».

---

## Пример карточки точки

```text
Бристоль

Глава: подготовка к плаванию

Из Бристоля начинается морское путешествие к острову сокровищ.

Вопрос:
Что бы ты взяла с собой в такое плавание?

[Моя заметка]

[Отметить как пройдено]
```

---

## Статусы мест

У каждой точки маршрута должен быть статус.

Возможные статусы:

* `real` — реальное место;
* `approximate` — примерное место;
* `fictional` — вымышленное место;
* `unknown` — нужно проверить.

На сайте можно показывать это простыми словами:

* Реальное место
* Примерное место
* Вымышленное место
* Нужно проверить

## Игровые элементы

В первой версии нужны только простые игровые элементы:

* отметка точки как пройденной;
* счётчик пройденных точек;
* финальное сообщение после завершения маршрута;
* звание за книгу.

Примеры званий:

* **Искательница сокровищ** — за «Остров сокровищ»;
* **Кругосветная путешественница** — за «Вокруг света за 80 дней»;
* **Путешественница к Одинокой горе** — за «Хоббита».

---

## Финальное сообщение

Когда все точки книги пройдены, показать:

```text
Маршрут завершён!
Ты прошла это книжное приключение.

Твоё звание:
Искательница сокровищ
```

---

## Что важно в дизайне

Сайт должен быть:

* лёгким;
* понятным;
* уютным;
* приключенческим;
* без перегруза;
* с крупной картой;
* с короткими текстами;
* с понятными кнопками.

Лучше использовать карточки, мягкие цвета и простые подписи.

---

## Что не делать в первой версии

Не добавлять сразу слишком много возможностей.

Пока не нужно:

* аккаунты;
* комментарии;
* рейтинги;
* тесты;
* сложные достижения;
* много настроек;
* загрузка изображений;
* админ-панель;
* база данных;
* мобильное приложение.

Главная цель первой версии — чтобы один маршрут работал хорошо.

---

## Цель первой версии

Минимальный успешный результат:

Пользователь открывает сайт, выбирает **«Остров сокровищ»**, видит карту, нажимает на точки маршрута, читает короткие описания, пишет заметки и отмечает путь как пройденный.

После этого можно добавлять новые книги.
