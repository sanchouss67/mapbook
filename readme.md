# Карта книжных путешествий

Open-source веб-сайт с интерактивными картами литературных путешествий. Пользователь выбирает книгу, видит маршрут героев на карте, кликает по точкам маршрута и читает краткое описание места, главы, эпизода и редакторскую заметку.

Первый MVP показывает один полноценный маршрут: **Жюль Верн — «Вокруг света за 80 дней»**.

## Что уже есть

- главная страница с заголовком, описанием и выбором книги;
- интерактивная карта на Leaflet и OpenStreetMap;
- линия маршрута и кликабельные точки;
- карточка выбранного места;
- таймлайн маршрута с перемещением карты к точке;
- JSON-данные маршрута в `data/books/around-the-world-in-80-days.json`;
- TypeScript-типы для будущих книг и маршрутов.

## Как запустить локально

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Как добавить новую книгу

1. Создайте новый JSON-файл в `data/books/`, например `treasure-island.json`.
2. Заполните данные в формате `BookRoute`: название, автора, описание и массив `route`.
3. Добавьте импорт нового файла в `app/page.tsx`.
4. Добавьте книгу в массив `books`.

Минимальный формат точки маршрута:

```json
{
  "order": 1,
  "place": "London",
  "displayName": "Лондон",
  "country": "Великобритания",
  "lat": 51.5072,
  "lng": -0.1276,
  "chapter": 1,
  "certainty": "exact",
  "transport": "start",
  "summary": "Краткое описание эпизода.",
  "quote": "",
  "note": "Заметка редактора."
}
```

Поле `certainty` поддерживает значения:

- `exact` — точное место;
- `approximate` — примерное место;
- `fictional` — вымышленное место.
